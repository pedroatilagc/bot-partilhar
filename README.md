## 💡 Por que este bot existe

Em agosto de 2026, por determinação da ANPD no âmbito do ECA Digital, o Discord suspendeu no Brasil o **Go Live**, o compartilhamento de tela e as chamadas de vídeo. Texto e voz continuaram funcionando, mas aquela partida, aquele filme ou aquela revisão de código em grupo deixou de ter onde ser mostrada.

O [PartilharTela](https://github.com/samuelmel) nasceu para preencher esse espaço: um site para compartilhar a tela ao vivo, sem cadastro, que funciona no navegador ou num app para Windows.

Faltava só uma coisa: **praticidade**. Abrir o site, criar a sala, copiar o código e colar no chat quebra o clima da call. Este bot resolve isso. A conversa continua no Discord, e a tela vai para o PartilharTela com um clique.

## ✨ O que ele faz

| | |
|---|---|
| ⚡ **Um comando** | `/tela` cria uma sala nova na hora |
| 🔗 **Um botão** | O link chega pronto no chat. Quem clicar já cai na sala |
| 🎙️ **Feito para a call** | Avisa em qual canal de voz você está, para a galera saber de onde veio o convite |
| 🏷️ **Com título** | Diga o que você vai mostrar: "Final do campeonato", "Bug do deploy"… |
| 🔒 **Sem cadastro** | Ninguém precisa criar conta. Basta ter o link |

## 🚀 Como usar

**1. Entre numa call** no servidor, como sempre.

**2. Digite `/tela`** em qualquer canal de texto e escolha o comando do PartilharTela.

> Quer dar um título? Com o comando selecionado, aperte **Tab** (ou clique em **+1 opcional**) e preencha o campo `titulo`.

**3. O bot posta o convite** com o código da sala e o botão **Entrar na sala**.

**4. Todo mundo clica no botão,** inclusive você, que vai transmitir.

**5. Escolha seu apelido e entre.** Lá dentro, clique em **Compartilhar tela** e escolha o que mostrar.

A voz continua no Discord. A imagem roda no PartilharTela. 🎉

> [!TIP]
> Se o bot ficar "pensando" por alguns segundos, é normal: o servidor do PartilharTela pode estar acordando. Na primeira vez do dia, isso pode levar até cerca de um minuto.

## 🎬 Dentro da sala

- **Qualquer pessoa pode transmitir.** A sala não tem dono da tela: mais de uma pessoa pode compartilhar ao mesmo tempo.
- **Cada um controla o próprio volume.** Abaixar ou silenciar o som de uma transmissão só muda para você.
- **Tela cheia** com um clique, para assistir como se fosse um vídeo.
- **Sair é só fechar a aba.** Você sai da sala na hora.
- **A sala expira em 12 horas.** Para outra sessão depois, é só usar `/tela` de novo.

## 🪟 Navegador ou app para Windows

As duas versões entram nas **mesmas salas**. A diferença está no som de quem transmite.

| | 🌐 Navegador | 💻 App Windows |
|---|:---:|:---:|
| Assistir uma sala | ✅ | ✅ |
| Transmitir tela ou janela | ✅ No computador | ✅ |
| Som junto | Aba do Chrome/Edge, ou tela inteira no Windows | Sistema inteiro ou só um aplicativo |
| Deixar o Discord **fora** do som | ❌ | ✅ |
| Escolher o que transmitir | Seletor do navegador | Lista com miniaturas |

**Para só assistir**, o navegador basta, inclusive no celular.
**Para transmitir com som sem levar o áudio da call junto**, use o app:

## ❓ Perguntas frequentes

<details>
<summary><b>O <code>/tela</code> não aparece quando eu digito.</b></summary>
<br>
Recarregue o Discord com <b>Ctrl+R</b>. Às vezes o aplicativo demora um pouco para buscar comandos novos.
</details>

<details>
<summary><b>Apareceu "Não consegui criar a sala".</b></summary>
<br>
O servidor do PartilharTela provavelmente estava hibernando. Espere alguns segundos e use <code>/tela</code> de novo.
</details>

<details>
<summary><b>Cliquei no link e a sala não existe mais.</b></summary>
<br>
As salas duram até 12 horas e podem ser encerradas se o servidor reiniciar. Crie outra com <code>/tela</code>.
</details>

<details>
<summary><b>Meus amigos não escutam o som da minha tela.</b></summary>
<br>
No navegador, o som só funciona no Chrome ou no Edge: compartilhando uma <b>aba</b> (marque "compartilhar áudio") ou a <b>tela inteira</b> no Windows. Firefox e Safari transmitem sem som. Para ter som de qualquer programa, use o app para Windows.
</details>

<details>
<summary><b>Dá para transmitir pelo celular?</b></summary>
<br>
Não. Celular e tablet só assistem. Para transmitir, use um computador.
</details>

<details>
<summary><b>Quem pode entrar na minha sala?</b></summary>
<br>
Qualquer pessoa com o link. Por isso, compartilhe o convite só nos canais do seu servidor.
</details>

<details>
<summary><b>Isso burla o bloqueio do Discord?</b></summary>
<br>
Não. Nenhum vídeo passa pelo Discord: o bot só envia uma mensagem com um link, como qualquer pessoa colando um endereço no chat. A transmissão acontece inteiramente no PartilharTela, fora do Discord.
</details>
